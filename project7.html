Nusantara Word Craft

Interactive Pixel-Art Web & Android Game

Status: In-Game / Native App

Mission Briefing

NusantaraWordCraft adalah proyek game berbasis pixel art yang mengangkat tema kebudayaan Nusantara dengan fokus pada mekanisme olah kata. Game ini dirancang sebagai aplikasi lintas platform yang dapat diakses melalui peramban web serta dikemas menjadi aplikasi Android menggunakan Capacitor.

Key Highlights & Tech Stack

  • Phaser Engine: Mengelola aset grafis, struktur adegan, dan logika pergerakan permainan 2D secara optimal.
  • Capacitor Integration: Mengonversi kode aplikasi berbasis web menjadi aplikasi mandiri untuk sistem operasi Android.
  • Visual & Tema: Menerapkan gaya estetika *pixel art* yang dipadukan dengan unsur kebudayaan lokal.

Equipped Tools

Phaser Framework JavaScript (ES6+) Capacitor (Android) HTML5 Canvas / CSS3
