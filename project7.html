NusantaraWordCraft

An Interactive Pixel Art Web Game based on Nusantara-themed Word Processing & Crafting.

NusantaraWordCraft adalah sebuah proyek Front-End Web Game berbasis pixel art interaktif yang dirancang untuk memberikan pengalaman bermain gim secara langsung melalui peramban (browser). Proyek ini berfokus pada mekanisme olah kata dan pembuatan konten bertema kebudayaan Nusantara.

Key Highlights & Tech Stack:

  • Interactive Gameplay: Menggunakan elemen Canvas / JavaScript untuk logika permainan yang responsif dan interaktif secara real-time.
  • Nusantara Theme: Mengangkat visual gaya pixel art dengan aset latar belakang dan audio bertema kearifan lokal.
  • Modern Deployment: Di-build dan di-deploy secara otomatis melalui Vercel CI/CD pipeline.
  • Technologies Used: HTML5 Canvas, Modern JavaScript (ES6+), CSS3 / Tailwind CSS.
